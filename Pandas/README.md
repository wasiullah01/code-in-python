# Pandas Practice Exercises

Beginner-friendly Python exercises for learning and practicing Pandas and NumPy.

## Overview

This folder contains eight exercises covering DataFrame basics, data filtering, data cleaning, CSV files, grouping, aggregation, and sales analysis.

## Topics Covered

1. `task9.1_dataframe_creation_access.py` - Creates a DataFrame and accesses its data.
2. `task9.2_filtering_statistics.py` - Filters data and calculates statistics.
3. `task9.3_filtering_statistics_alternative.py` - Provides another filtering and statistics practice.
4. `task9.4_data_cleaning.py` - Handles missing values and duplicate data.
5. `task9.5_data_cleaning_csv_export.py` - Cleans data and exports it to a CSV file.
6. `task9.6_csv_read_write.py` - Writes, reads, and reports CSV data.
7. `task9.7_groupby_aggregation.py` - Groups data and calculates results by subject.
8. `task9.8_sales_analysis.py` - Analyzes sales and revenue by product and city.

## Requirements

- Python 3.8 or newer
- Pandas
- NumPy

## Installation

Install the required packages with:

```bash
pip install pandas numpy
```

## Running the Exercises

Open a terminal in this folder and run any exercise:

```bash
python task9.1_dataframe_creation_access.py
python task9.2_filtering_statistics.py
python task9.7_groupby_aggregation.py
python task9.8_sales_analysis.py
```

## Generated Files

Some exercises create output files in this folder:

- `Clean_Data.csv`
- `Student_Cleaned.csv`
- `Groups.csv`
- `Analysis.csv`
- `Student_clean.txt`
- `Sales Analysis.txt`

## Learning Goals

These exercises provide practice with:

- Creating and accessing Pandas DataFrames
- Filtering rows and selecting columns
- Calculating basic statistics
- Cleaning missing and duplicate data
- Reading and writing CSV files
- Grouping data and calculating aggregations
- Analyzing sales revenue by product and city
